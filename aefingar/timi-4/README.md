# Mælikvarði í verki — Lota 28, 4. tími

Heimild: „28.4 dæmi.pdf“, tveggja síðna verkefnablað „Mælikvarði“.
Báðar síður og myndir skoðaðar. Nýjar sambærilegar tölur, þrjú afbrigði.
Sex meginhlutar (17 skref) og valfrjáls viðbót (3 skref).

Húsgaflinn og sýndarreglustikan nota sama tölugagnasett og sömu hnitavörpun.
Nemandi les sentímetra af reglustiku inni í myndinni; það þarf ekki líkamlega
reglustiku eða skjákvörðun. Hlutföll hæðar og breiddar haldast rétt við
skjábreytingar. Turnar, póstkort og kortalína eru merkt sem skýringarmyndir.

Mælikvarðinn er alltaf mynd : raun. Stórar tölur mega innihalda bil.
Komma og punktur samþykkt sem tugabrotsmerki; þrír aukastafir þar sem þess þarf.
